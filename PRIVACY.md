# Privacidad

CRAFTERRA v0.1.0 no recopila, transmite, vende ni comparte datos personales. No incluye analítica, rastreadores, cuentas, anuncios reales ni pagos. El progreso, preferencias y estadísticas se almacenan exclusivamente en IndexedDB del navegador. El usuario puede exportar o borrar sus datos desde Ajustes, o eliminar los datos del sitio mediante el navegador.

Los botones comerciales y recompensas publicitarias están marcados como DEVELOPMENT y simulan únicamente una respuesta local. Si una versión futura integra proveedores externos, esta política deberá actualizarse antes de publicarla y deberá informar de proveedores, finalidades, base jurídica, conservación y mecanismos de eliminación.
