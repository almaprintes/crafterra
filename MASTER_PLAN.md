# CRAF TERRA — Catálogo maestro v0.2.0

Esta versión sustituye el catálogo experimental anterior por una estructura cerrada y auditable.

## Resultado
- 237 objetos únicos.
- 232 recetas explícitas, una para cada objeto no inicial.
- 237/237 objetos alcanzables desde Piedra, Madera, Agua, Fuego y Tierra.
- 21 colecciones.
- 28 misiones de progresión.
- 15 puzles.
- 25 logros.
- 10 estaciones de trabajo.
- `Cristal rojo` eliminado.
- Eliminado el relleno automático de recetas.
- Eliminadas referencias rotas a zinc, níquel y flor.
- Eliminado el duplicado nominal de Madera.

## Reglas del catálogo
1. Cada ID es único y estable.
2. Cada nombre visible es único.
3. Cada par de ingredientes produce un único resultado.
4. No existen recetas generadas para alcanzar una cifra arbitraria.
5. Todos los objetos forman parte de una cadena de progresión alcanzable.
6. La progresión avanza por: Origen → Supervivencia → Oficio → Mecánica → Precisión → Electricidad y ciencia → Cumbre tecnológica.
